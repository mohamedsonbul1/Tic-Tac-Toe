# Tic-tac-toe

Two players, editable names, a move log and a game-over overlay with rematch. The board is derived from the log of turns rather than stored separately, which is the lesson this exercise was about: lifting state up and computing derived state instead of duplicating it.

React 18 + Vite.

```bash
npm install && npm run dev
```

# Tic-Tac-Toe

Zwei Spieler, editierbare Namen, ein Zugprotokoll und ein Game-Over-Overlay mit Revanche. Das Brett wird aus dem Zugprotokoll abgeleitet statt separat gespeichert – genau darum ging es in dieser Übung: State nach oben ziehen und abgeleiteten State berechnen statt ihn zu duplizieren.
